# iOS app

SwiftUI, iOS 17 and up. The Xcode project is generated from `project.yml` with [XcodeGen](https://github.com/yonaskolb/XcodeGen), so change settings there or in `Config.xcconfig`, then run `xcodegen generate`.

Your own keys and Apple team go in two gitignored files: `AchillesRecovery/Config/Secrets.swift` and `Local.xcconfig`. Full setup is in the [docs](../docs/content/getting-started.mdx).
